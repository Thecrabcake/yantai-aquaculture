# 烟台海产养殖行情助手 — 设计文档

日期：2026-09-25
状态：待用户确认

## 1. 项目背景

帮朋友做的项目。朋友在烟台海阳市经营海产相关业务：

- 春季：南美白虾养殖
- 冬季（11 月起）：暂养皮皮虾 + 梭子蟹
- 另有：生蚝加工厂

关键事实：

- **朋友是新手**（没养过），需要了解行业
- 基础电脑水平，**每天用手机看**行情
- 无任何历史经营数据 → 从公开数据起步
- 开发者为朋友的朋友（本项目的用户），项目移交后由朋友自己使用

## 2. 目标

把行情侧的信息差抹平。做一个水产版"炒股工具"：看走势、估价格区间、读行业新闻、算成本、学避坑。

**不做的：** 价格点预测（只给区间和概率）、替朋友做决策、技术前沿调研（后续可加）。

## 3. 一期范围（6 个模块）

| # | 模块 | 内容 | 优先级 |
|---|---|---|---|
| 1 | 价格走势图 | 南美白虾 / 皮皮虾 / 梭子蟹 / 生蚝，手机优先，标注春节/中秋 | 必做 |
| 2 | 价格区间预测器 | 输入投苗时间 + 预计出虾时间 → 出虾窗口的历史价格区间 + 情景修正 | 必做 |
| 3 | 新闻雷达 | 病害 / 进口 / 政策 / 天气，每日或每周汇总 | 必做 |
| 4 | 成本计算器 | 苗 / 饲料 / 电 / 药 → 保本价 | 必做 |
| 5 | 新手内容 | 养殖时间轴 + 避坑清单 | 推荐 |
| 6 | 行业月报 | 每月一页纸，微信可发 | 已定 |

**记账模块**：只设计数据结构与接口，不实现。移交朋友时再做（届时朋友每天记几分钟进销价，是其长期最有价值的资产）。

## 4. 架构

```
Python 爬虫/整理脚本 → SQLite → 静态网页生成 → 本地浏览器/手机访问
```

- 技术栈：Python（爬虫、整理、生成）+ SQLite（存储）+ 单文件/静态 HTML+JS（页面，ECharts 图表）
- 部署：**先本地跑通**（开发者电脑运行），朋友验收后再定（国内轻量服务器或免费静态托管）
- 数据链路可手动重跑，脚本需容错（单个源失败不拖垮整体）
- 无后端、无账号体系、无实时要求

## 5. 数据源（实施第一步验证）

| 数据 | 来源 | 频率 | 风险 |
|---|---|---|---|
| 水产品批发价 | 农业农村部监测数据 | 月度 | 低 |
| 虾类进口量 | 海关总署 | 月度 | 低 |
| 周度报价（含皮皮虾） | 惠农网 / 批发市场行情 | 周度 | 中：反爬、皮皮虾稀疏 |
| 行业新闻 | 水产门户、政府网站、公众号 | 每日/每周 | 中：可爬性待验证 |

**验证不过就换源。** 皮皮虾数据缺口是已知风险，先接受"数据少"的现状，有记录比没有强。

公开数据是全国批发价口径，与海阳当地出塘价存在价差——长期靠记账模块补齐，一期先用全国口径 + 看板中标注口径差异。

## 6. 预测器设计

- **输入**：投苗时间、预计出虾时间（可选品种）
- **输出**：近 5 年该出虾窗口的价格分布——中位数、常规波动区间（如 25%-75% 分位）、当前所处历史分位
- **情景修正**：叠加今年特殊因素（进口量趋势、病害年、节假日窗口）往区间内修正
- **原则：给区间不给点，给概率不给保证**。页面明示"历史统计，不构成预测保证"

## 7. 周期分析框架（知识底座，用于解读与月报）

- **三层叠加**：趋势层（进口/消费升级，以年计）、季节层（每年重现，最可利用）、冲击层（病害/台风/进口突增，随机）
- 虾：4-5 月投苗 → 7-9 月集中上市价格谷底 → 10 月后收缩，春节前最高；病害→投苗反馈环是周期发动机
- 蟹/皮皮虾：9-11 月集中上市价低，入冬货源断，春节前价高；暂养本质是"损耗+成本 赌 春节价差"
- 生蚝：冬肥夏瘦，9 月-次年 4 月肥美期
- **领先指标**：投苗量、进口量、病害报告、鱼粉价格
- 具体数值待数据到位后量化校准

## 8. 页面结构

| 页 | 内容 |
|---|---|
| 首页/走势 | 三品种价格曲线，春节/中秋标注，手机优先 |
| 预测器 | 表单 → 区间结果（含"历史统计"免责说明） |
| 新闻 | 按日期/类别列表 |
| 成本 | 保本价计算表单 |
| 新手 | 养殖时间轴 + 避坑清单 |

月报为独立交付物（一页纸 HTML/PDF，微信发送），不在网页内。

## 9. 里程碑（5 段验收，每段可停）

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M1 | 数据源验证 + 爬虫管道 + SQLite | 三品种价格数据落库，可重复跑 |
| M2 | 走势图看板 | 本地打开可见历史曲线，手机布局正常 |
| M3 | 预测器 | 输入投苗/出虾时间返回历史区间 |
| M4 | 新闻雷达 | 先人工周选两月验证，之后决定是否自动化 |
| M5 | 成本计算器 + 新手内容 + 月报模板 | 全部可用，本地验收 |

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 数据源反爬/稀疏（皮皮虾） | M1 先验证，失败换源；数据少也保留 |
| 全国口径 vs 海阳当地价差 | 页面标注口径；长期靠记账模块 |
| 朋友不看（白做风险） | 新闻先人工跑两个月验证真实使用 |
| 新手第一年最大坑在养殖本身 | 工具定位明确，新手内容尽量覆盖操作避坑 |
| 内容质量（不能瞎写） | 新手内容/月报以可查证来源为准 |

## 11. 边界

- 不做价格预测保证，只给历史统计和区间
- 不替朋友做决策，工具交到他手上
- 记账模块一期只设计不实现，移交时再做
- 技术前沿调研不在本期范围
