# 维护手册

面向维护者（开发电脑上操作）。手机端是纯静态页面，只需定期更新数据后重新生成。

## 一、每周更新流程（约 10 分钟）

```bash
cd yantai-aquaculture
# 1. 更新数据（抓月报 + 惠农网生蚝价 + 读录入档，幂等可重复跑）
PYTHONPATH=src python -c "from aqua import pipeline; pipeline.run('data/aquarium.db', csv_dir='data')"
# 2. 重新生成站点
PYTHONPATH=src python -c "from aqua.web import build; build.build('data/aquarium.db', 'site')"
# 3. 推送线上（朋友手机看 https://thecrabcake.github.io/yantai-aquaculture/）
cd site && git add . && git commit -m "站点更新" && git push && cd ..
```

站点服务保持运行即可（`python -m http.server 8000 --directory site`），重建后手机刷新页面即见新数据；推送后 1-2 分钟线上生效。

## 二、人工录入格式

### 1. 新闻周选 `data/news_manual.json`

每周用 WebSearch 搜四类新闻：**病害 / 进口 / 政策 / 天气**，每类 1-3 条，只录有明确日期和来源的。追加到 JSON 数组（旧条目保留，入库按"日期+标题"自动去重）：

```json
{"date": "2026-09-25", "category": "病害", "title": "标题",
 "summary": "一两句话摘要，写清对价格/养殖的影响",
 "url": "https://...", "source": "来源媒体"}
```

四类 tag 颜色：病害=红、进口=蓝、政策=绿、天气=橙（news.html 内置）。

### 2. 品种价格周录 `data/price_manual.json`

每周从新闻报道/市场问价收集品种报价（白虾/皮皮虾/梭子蟹），只录有明确日期来源的，宁缺毋假。字段：`name`（可用别名，自动归一化）、`date`、`price`（元/斤）、`unit`（元/斤 或 元/公斤）、`market`、`source`。区间价可用 `price_low`/`price_high`。

生蚝不需要周录：惠农网每日产地价由 pipeline 自动抓取（频道 ID 在 `src/aqua/sources/huinong.py` 的 CHANNELS；其他品种频道 ID 找到后加进同一字典即可自动启用）。

### 3. 进口量月录 `data/import_manual.json`

每月海关数据公布后录入暖水虾进口量（吨）：

```json
{"ym": "2026-05", "product": "暖水虾", "volume_ton": 88000, "source": "海关月度"}
```

## 三、常见问题

- **某源失败**：pipeline 打印 `[pipeline] xx 失败，跳过`，不影响其他源；网络问题时重跑即可（有 3 次重试）。
- **手机打不开**：确认电脑没休眠、IP 没变（`ipconfig` 查 IPv4），手机与电脑同一 WiFi。
- **数据没更新**：检查是否跑了第 2 步 build，手机需刷新页面。
- **测试**：`PYTHONPATH=src python -m pytest tests/`，20+ 测试应全绿。
